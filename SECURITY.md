# Security Policy

Dixlase OnePage is part of the Dixlase Project. Security reporting is coordinated centrally across the Project — there is no separate per-theme disclosure channel.

For the Japanese version, see [SECURITY.ja.md](./SECURITY.ja.md).

## Reporting a vulnerability

**Please do not file public GitHub Issues for security vulnerabilities.**

To report a vulnerability in Dixlase OnePage (or in any Dixlase component), follow the disclosure process documented in the Dixlase Core repository:

- https://github.com/Dixlase/dixlase-core/blob/main/SECURITY.md

When reporting, please mention that the vulnerability is in **Dixlase OnePage** (this theme) so the maintainers can route the report correctly.

## Supported versions

Until a stable 1.0 release is published, only the latest tagged release of Dixlase OnePage receives security fixes. Pre-1.0 versions may be superseded without backports.

## Scope

This policy covers code in the [`theme-dixlase-onepage`](https://github.com/Dixlase/theme-dixlase-onepage) repository. Vulnerabilities in Dixlase Core, official plugins, or third-party dependencies should be reported to their respective maintainers via the channels listed in Core's `SECURITY.md`.
