# Dixlase OnePage

Dixlase OnePage テーマ。プラグイン連動型のシングルページ/LP用テーマ。

## 概要

- **バージョン**: 1.0.0
- **ライセンス**: GPL-3.0-or-later (デュアルライセンス)
- **作者**: exc-D inc.
- **必要環境**: PHP 8.2+, Dixlase 1.0.0+

## 特徴

- ✅ レスポンシブデザイン
- ✅ ダークモード対応
- ✅ フロントページビルダー対応
- ✅ CSS変数でカスタマイズ可能
- ✅ 多言語対応（日本語・英語）
- ✅ アクセシビリティ対応
- ✅ SEO最適化

## クイックスタート

```bash
# テーマディレクトリに移動
cd themes/DixlaseOnePage

# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# 本番ビルド
npm run build
```
