# Dixlase OnePage

For English, see [README.md](./README.md).

Dixlase をインストールすると標準で同梱されるデフォルトテーマ。  
プラグイン連動型のシングルページ / ランディングページ用テーマ。

## 機能

- **ヒーローセクション** — 背景画像 / 動画、メインタイトル、サブタイトル、ON/OFF できる CTA ボタン 2 つ。
- **ヘッダー / フッター** — ロゴ、ファビコン、説明文、年が自動更新されるコピーライト、SNS リンク枠。
- **ダークモード & プライマリカラー** — 自動 / ライト / ダーク、アクセントカラーは固定パレットから選択。
- **プラグインスロット** — ヘッダー / フッターメニュー（DixlaseMenus）、お問い合わせフォーム（DixlaseInquiry）。
- **フロントページビルダー** — DixlasePages のコンテンツをインラインで描画。

## インストール

**Dixlase Core に同梱**。Core の初回インストール時に自動でインストール・有効化されます。  
管理画面の「ダッシュボード → プラグイン」操作は不要です。

## 使い方

**ダッシュボード → 外観 → テーマ設定** からヒーロー、ヘッダー / フッター、デフォルト言語、プライマリカラー、外観モード、プラグインスロットを編集します。

## ドキュメント

テーマ専用のドキュメントサイトは今後用意する予定です。それまでの間は管理画面の **テーマ設定** が情報源です。
