# Dixlase OnePage

For English, see [README.md](./README.md).

Dixlase をインストールすると標準で同梱されるデフォルトテーマ。プラグイン連動型のシングルページ / ランディングページ用テーマで、設定可能なヒーロー（画像または動画背景、見出し、サブ見出し、プライマリ / セカンダリの CTA ボタン）、ヘッダーロゴとファビコン、説明文 / コピーライト / SNS リンクを備えたフッター、ダークモード対応、プライマリカラーピッカー、言語スイッチャーとお問い合わせフォームのプラグイン連携、多言語ランタイム経由でヒーロー文言を翻訳可能、といった構成。

## 機能

- **シングルページレイアウト** — ヒーロー、任意のフロントページコンテンツ、フッターを 1 つのルートで描画。
- **ヒーローセクション** — 背景画像 / 動画、メインタイトル、サブタイトル、設定で個別に ON/OFF できる CTA ボタン 2 つ。
- **ヘッダー** — ロゴとファビコン、DixlaseMenus が有効ならアクティブなサイトメニューを描画。
- **フッター** — 説明文、年が自動更新されるコピーライト、リンク一覧、12 個程度の SNS リンク枠（Instagram / X / Facebook / TikTok / Bluesky / Threads / LinkedIn / YouTube / Pinterest / Discord / GitHub）。
- **ダークモード** — 自動（OS に追従）/ ライト / ダークを設定から選択。
- **プライマリカラー** — ボタンやリンクに使うアクセントカラーを固定パレットから選択。
- **ヒーロー文言の多言語化** — ヒーローのタイトル / サブタイトル / ボタンラベルは `dixlase-onepage:settings` のシングルトンとして翻訳可能。執筆言語（default locale）を明示的に設定でき、その言語は翻訳エディタのセレクタから除外される。
- **プラグイン連携** — ヘッダー / フッターナビゲーションに DixlaseMenus、フッター上部のお問い合わせフォームに DixlaseInquiry、言語スイッチャーに DixlaseMultilingual を利用。
- **フロントページビルダー** — DixlasePages と多言語ランタイムが揃っている場合、ページビルダーで作ったフロントページコンテンツがヒーローとフッターの間にインラインで描画される。

## インストール

**Dixlase Core に同梱**。本テーマは Core を初めてインストールするタイミングで自動的にインストール・有効化されます。管理画面からの「ダウンロード → 有効化」操作は不要です。インストールウィザードがテーマのマイグレーションとシーダーを実行し、ウェルカム画面の直前にアクティブテーマを OnePage に切り替えます。

サイト稼働後はテーマ管理画面から通常通り再適用・切替が可能です。

## 使い方

インストール後、トップルートは OnePage レイアウトで描画されます。**ダッシュボード → 外観 → テーマ設定** を開いて以下を編集できます。

- ヒーロー背景（画像 / 動画）、メインタイトル、サブタイトル、ボタンテキストとリンク、ボタン表示の ON/OFF。
- ヘッダーロゴとファビコン。
- フッターの説明文、リンク、コピーライト末尾、プラットフォームごとの SNS URL。
- デフォルト言語（ヒーロー文言を書く言語）、プライマリカラー、外観モード。
- プラグインスロット: ヘッダーメニュー、フッターメニュー、お問い合わせフォームの ON/OFF。

ヒーロー文言の翻訳は、DixlaseMultilingual が有効な場合に中央翻訳マネージャから編集します。

## Capabilities

本テーマは `theme.json` で以下の capability を宣言しています。

- **`multilingual-content`** — テーマの翻訳可能ヒーロー文言を singleton cardinality として登録。プロバイダ（`DixlaseOnePageSettingsProvider`）はテーマ自身の設定テーブルから primary 言語の値を読み、現在ロケールが設定済み default locale と一致した場合は翻訳ルックアップをショートサーキットする。
